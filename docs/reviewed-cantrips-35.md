# Level 0 spell review for D&D Tools

This review covers 74 suggested names. It concerns the D&D Tools spell catalog
only. Source and edition checks were made in the earlier bibliographic review;
the names and local database state were checked again for this import. A name
can have multiple publication-specific records in D&D Tools. IDs from another
catalog are not used here.

Outcome: 28 candidates already had a confirmed 3.5 entry, seven reviewed 3.5
entries were added, 36 need further source or edition decisions, and three
are not level 0 spells in an applicable 3.5 publication. The local SQLite
database now contains 4,918 spells. Its new rows are local; the public fork
ships the reviewed data and `import_reviewed_cantrips` command, not the database.

The seven new records have source URLs, page numbers, class levels, components,
and original English summaries in
`dndtools/dnd/data/reviewed_cantrips_35.json`. These summaries paraphrase the
effects; they do not reproduce source text. The D&D Tools schema does not
store per-spell provenance URLs or aliases, so those stay in the versioned
data file. No existing spell rows were rewritten.

To preview or import into a configured, prepopulated database:

```powershell
.\.venv\Scripts\python.exe dndtools\manage.py import_reviewed_cantrips
.\.venv\Scripts\python.exe dndtools\manage.py import_reviewed_cantrips --apply
```

The command checks identities and class levels before writing, uses an atomic
transaction, and can be rerun without adding copies. Back up the SQLite file
before applying it to another installation.
